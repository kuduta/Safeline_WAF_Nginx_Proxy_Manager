02 / ตรวจจุดที่กำลังเข้า

พอร์ต 18080 เข้าต้นทางโดยตรง และ 8080 ผ่าน NPM เท่านั้น ทั้งสองแบบใช้เปรียบเทียบ baseline ไม่ได้ยืนยันการป้องกัน WAF

หลังเพิ่มเว็บไซต์ใน SafeLine ให้เปิด http://waf-test.localhost ผ่านพอร์ต 80 เพื่อทดสอบครบเส้นทาง

HTTP 200 พร้อม origin “waf-test-site” หมายถึง request ถึงต้นทาง ส่วน status อื่นต้องดู response และ log ของ SafeLine ประกอบ ไม่ได้แปลว่าถูก WAF บล็อกเสมอไป
